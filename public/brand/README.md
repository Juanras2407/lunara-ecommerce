# Logo de la tienda

Colocá tu logo aquí:

- **Carpeta**: `lunara-ecommerce/public/brand/`
- **Nombre**: `logo.png` (exacto, en minúsculas)
- **Formato**: PNG con fondo transparente (recomendado) o JPG
- **Tamaño**: cuadrado, mínimo 200x200px, ideal 512x512px

El header lo muestra como una imagen cuadrada redondeada de 36px de alto.
Si no hay archivo, se muestra la inicial del negocio como respaldo.

> Nota: si subís un logo desde el POS (módulo **Branding**), ese se guarda en
> Cloudinary y tiene prioridad sobre este archivo. Esta carpeta es el fallback
> estático para cuando la organización todavía no tiene logo subido.
